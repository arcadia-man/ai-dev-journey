# Vector Search — Movie Recommendation

## What you learn here

- What a vector embedding is and why it captures meaning
- How cosine similarity ranks results by semantic distance (not keywords)
- The full layered architecture: Model → Repository → Service → Controller → Route
- Why we run a seeder once instead of embedding on every request

## How it works

```
User types: "space exploration and survival"
         ↓
Server embeds the query → queryVector (768 numbers)
         ↓
Load all movies (each has a stored embedding from the seeder)
         ↓
cosineSimilarity(queryVector, movieVector) for each movie
         ↓
Sort by score, return top 5
```

No keyword matching. "Interstellar" ranks high for "space survival" because
its embedding vector points in the same direction as the query vector.

## Setup

```bash
cp .env.example .env
npm install

# Generate embeddings for all movies (run once)
npm run seed

# Start the server
npm start
```

Open http://localhost:3000
